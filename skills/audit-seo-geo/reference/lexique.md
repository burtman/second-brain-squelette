# Lexique pour les livrables client

> Au premier emploi d'un terme dans un document client, on met sa traduction entre parenthèses. Le lexique en fin
> de Diagnostic reprend uniquement les termes employés dans ce document-là. On n'explique jamais un mot technique
> avec un autre.

| Terme | En clair |
|---|---|
| SEO | ce qui fait remonter un site dans Google quand on cherche ce qu'il propose |
| GEO | la même chose pour les assistants comme ChatGPT : être nommé dans leurs réponses |
| Citation par une IA | le moment où un assistant nomme la marque ou donne son lien dans sa réponse |
| AI Overview | le résumé écrit par Google au-dessus des liens, sur certaines recherches |
| Page de résultats | la liste de liens que Google affiche après une recherche |
| Title | le titre bleu cliquable qui apparaît dans Google |
| Meta description | les deux lignes grises sous ce titre |
| H1, H2 | le grand titre de la page, puis ses intertitres |
| Indexation | le fait que Google a bien enregistré une page ; une page non indexée ne peut pas sortir |
| Sitemap | la liste de toutes les pages, donnée à Google pour qu'il n'en oublie aucune |
| robots.txt | le fichier qui dit aux robots des moteurs et des IA ce qu'ils ont le droit de lire |
| Robot (crawler) | le programme d'un moteur ou d'une IA qui parcourt les sites pour les lire |
| llms.txt | un petit fichier qui présente le site aux assistants IA, en quelques lignes |
| Canonical | une étiquette qui indique à Google quelle version d'une page est la bonne, quand il en existe plusieurs |
| Redirection 301 | un renvoi définitif d'une adresse vers une autre |
| Données structurées (JSON-LD) | une fiche descriptive invisible pour les visiteurs, lue par les moteurs : qui vous êtes, ce que vous vendez |
| sameAs | la ligne de cette fiche qui liste vos comptes officiels sur les réseaux |
| Résultat enrichi | un résultat Google avec des étoiles, des prix ou des questions dépliables |
| Fiche Google (Google Business Profile) | la fiche de l'entreprise qu'on voit sur Google Maps et à côté des résultats de recherche |
| NAP | le nom, l'adresse et le téléphone, à écrire exactement pareil partout |
| Panneau de connaissance | l'encart récapitulatif qu'affiche Google pour une marque ou une personne connue |
| Wikidata | la base de données publique qui identifie les entreprises, personnes et lieux, et que les IA consultent |
| Lien entrant (backlink) | quand un site extérieur met un lien vers vous ; Google le lit comme une recommandation |
| Maillage interne | les liens entre vos propres pages |
| Intention de recherche | ce que la personne veut vraiment quand elle tape sa recherche |
| Longue traîne | les recherches longues et précises, rares une à une mais nombreuses au total |
| Signaux de confiance (E-E-A-T) | ce qui montre qui est derrière le site et pourquoi on peut le croire |
| Paragraphe-réponse | 40 à 60 mots qui répondent tout de suite à la question, en haut de page ou sous un intertitre ; c'est ce que les IA reprennent le plus volontiers |
| Part de voix | la part des citations qui vous reviennent, face à vos concurrents, dans les réponses des IA |
| Core Web Vitals | les mesures de vitesse et de stabilité d'une page sur téléphone |
