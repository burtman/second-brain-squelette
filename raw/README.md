# raw/ — sources brutes

Source de vérité. L'humain dépose ici (articles, PDF, transcripts, exports). L'agent **lit, ne réécrit jamais**.

- Un sous-dossier par thème ou par corpus : `raw/<THEME>/`.
- Chaque dossier porte un `SOURCES.md` : tableau des sources primaires, secondaires et **exclues** (avec la raison).
- Rien au-dessus de 1 Mo sans accord explicite : on dépose la transcription Markdown, l'original reste à sa source.
